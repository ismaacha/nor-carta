# Fotos de la carta

Guarda cada foto con **exactamente** este nombre y aparecerá sola en la web (no hace falta tocar el código).
Si una foto no existe, se ve una foto de muestra o un degradado con el color del apartado.

Recomendado: formato **.jpg**, horizontal o cuadrada, unos 1200 px de ancho y menos de 300 KB.
